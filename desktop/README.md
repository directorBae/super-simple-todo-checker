# 할 일 체커

간결한 개인 할 일 관리 데스크톱 앱 (Electron + React).

## 기능

- **할 일**: 일 단위 할 일. 날짜 + 시작/마무리 시간 지정 가능.
- **프로젝트**: 장기/단기 프로젝트. 할 일을 묶을 수 있고 진행률이 표시됨.
- **팀**: 프로젝트와 할 일을 소속 팀으로 묶음.
- **버킷 (Buckets)**: 아직 애매하지만 챙기고 싶은 할 일·프로젝트를 담아 두고, 준비되면 활성화. (팀에는 적용 안 됨)
- **알림**:
  - 시작 시간 알림 / 마무리 시간 알림 (Windows 토스트)
  - 아침 요약 알림 (오늘 할 일 개수, 시간 설정 가능)
  - 하루 마무리 알림 (완료한 일 · 남은 일 요약, 시간 설정 가능, 기본 21:00)
  - **밀린 알림 버퍼링**: 컴퓨터가 꺼져 있는 동안 지나간 알림은 켜졌을 때 "밀린 알림 N건" 요약 1건으로 표시 → 클릭하면 앱의 '알림' 탭에서 목록 확인
- **도구 연결**: Notion·Google Calendar·iCloud 양방향 연동, 조직별 분리, OpenAI 자동 분배.
- **트레이 상주**: 창을 닫아도 백그라운드에서 실행되며 알림 발송. 완전 종료는 트레이 아이콘 → 종료.
- **자동 시작**: 설정에서 Windows 부팅 시 자동 실행(백그라운드) 켜기 가능.

## 실행

```bash
npm install

# 개발 모드 (핫 리로드)
npm run dev

# 일반 실행 (빌드 후 실행)
npm start
```

데이터는 `%APPDATA%/todo-checklist/db.json` 한 파일에 저장됩니다.

## API 연결 설정

[개인용 API 설정 가이드](../docs/integration-setup.md)를 따른다. 서버를 실행하고 앱에서 계정·위치·조직을 선택한다. 기존 읽기 전용 Google 연결은 새 서버 OAuth 연결로 다시 등록한다.

## 참고

- 개발 모드(`npm run dev` / `npm start`)에서는 Windows 알림에 앱 이름이 "Electron"으로 표시될 수 있습니다. 배포 패키징(electron-builder) 시 정상 표시됩니다.
- "Windows 시작 시 자동 실행"은 개발 모드에서는 현재 electron 실행 경로가 등록되므로, 배포 빌드에서 사용하는 것을 권장합니다.
