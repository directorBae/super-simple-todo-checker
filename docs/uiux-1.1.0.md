# 체커 1.1.0 — PC · 모바일

## 바뀐 화면

- 처음 실행하면 도구 연결 전용 전체 화면이 열린다. Notion, Google Calendar, Apple Calendar를 연결하거나 ‘지금은 건너뛰기’를 선택할 수 있다. 다음 실행에서는 반복하지 않는다.
- 상단에는 체커 또는 TODOs만 표시한다. 도구 연결은 PC 상단의 강조 버튼과 모바일 하단 탭에서 바로 연다.
- 도구 화면에는 세 도구의 아이콘 카드만 표시한다. 계정 로그인, Notion 토큰, 데이터베이스/캘린더 선택, 팀 지정은 카드 안의 별도 창에서 진행한다. 같은 팀에 계정과 데이터베이스를 여러 개 연결할 수 있다.
- 프로젝트 탭을 팀 탭으로 바꿨다. 기존 프로젝트의 팀 소속은 할 일에 직접 옮기고, 팀이 없던 프로젝트는 같은 이름의 팀으로 전환한다. 기존 할 일을 삭제하지 않는다.
- 테마는 메뉴에서 바로 변경한다. 모바일은 클리어·미드나이트·오로라·선셋을 제공한다.
- 월 뷰로 시작한다. 모바일은 월 달력 아래에서 선택한 날짜의 할 일을 바로 작성한다.
- 유리 패널, 반투명 테두리와 배경 블러를 공통 적용한다. 지원되는 iPhone에서는 네이티브 Liquid Glass를 사용한다. 다른 iPhone은 네이티브 BlurView, Android 12 이상은 BlurTargetView 기반 블러를 사용하고 이전 Android는 반투명 표면으로 표시한다.

## 모바일 조작

- 제목을 누르면 그 자리에서 편집한다. 줄바꿈으로 다음 할 일을 만들며 여러 줄 붙여넣기도 지원한다.
- 새 입력 줄에서 내용 없이 Backspace를 누르면 마지막 할 일로 돌아간다. 기존 빈 줄에서는 해당 할 일을 삭제하고 이전 줄로 이동한다. 줄 맨 앞에서 Backspace를 누르면 이전 줄 끝에 합친다.
- 할 일 오른쪽 달력 버튼은 날짜만 고르는 창을 연다. AI 목적지, 원본 ID, 중복 종료 날짜 등은 표시하지 않는다. 가져온 일정의 시간과 여러 날에 걸친 기간은 내부 데이터로 보존한다.
- 편집 중이 아닌 줄을 오른쪽으로 밀면 버킷으로, 왼쪽으로 밀면 삭제한다. 하단의 되돌리기로 취소할 수 있다.
- 줄 왼쪽 점 손잡이를 길게 누르면 팀 선택 영역이 나타난다. 팀 위로 끌어 놓거나 팀을 눌러 이동한다. 목록의 다른 줄 위로 끌어 놓으면 순서가 바뀐다.
- 중복 판단의 개인 메모리와 OpenAI 설정은 도구 화면이나 할 일 편집기에 표시하지 않는다. 개인 메모리는 서버에 유지한다.

## PC와 휴대폰 연결 — 한 번만 설정

1. 현재 PC 서버는 업데이트되어 실행 중이다. 이전 `.env`, SQLite 데이터와 서버 토큰은 그대로 유지했다. 서버를 두 개 실행하지 않는다.
2. Windows 설치 파일로 PC 앱을 업데이트한다. 새 PC 앱은 이 컴퓨터에서 실행한 서버 연결 정보를 자동으로 읽는다.
3. [휴대폰 접속 허용 실행 파일](../server/allow-phone-connection.cmd)을 실행하고 Windows 관리자 권한 요청을 승인한다. 개인 네트워크의 로컬 기기에서 TCP 8787로 접속하는 규칙만 추가한다. 자동 적용은 Windows의 관리자 권한 부족으로 거부되어 이 단계는 사용자가 실행해야 한다.
4. PC 앱 메뉴 → **휴대폰 연결**을 선택한다. Wi-Fi 주소와 6자리 코드가 나타난다. 코드는 10분 동안 한 번만 사용할 수 있다.
5. PC와 같은 Wi-Fi에 연결한 휴대폰에서 메뉴 → **PC 연결 · 동기화**를 연다. 현재 PC의 주소는 `http://192.168.150.151:8787`이다. PC에 표시된 연결 코드를 입력한다. 휴대폰의 `localhost`는 PC를 가리키지 않는다.
6. iPhone에서 로컬 네트워크 접근을 허용한다. 이전에 거부했다면 iPhone 설정의 체커 앱 권한에서 켠다.
7. 이후 수정 사항은 약 650ms 후 전송하고 실행 중에는 약 3초마다 다른 기기의 변경을 확인한다. 앱을 다시 활성화하면 즉시 동기화한다. 오프라인 변경은 기기에 저장했다가 다음 연결에 반영한다. 같은 할 일을 양쪽에서 고쳤다면 더 최근 수정이 적용된다.

Google OAuth 콜백이 localhost로 등록되어 있으므로 **Google 로그인은 PC 앱에서** 완료한다. 연결된 계정과 일정은 같은 서버를 사용하는 휴대폰에서도 보인다. Notion과 iCloud는 휴대폰 팝업에서도 연결할 수 있다.

## 검증 범위

서버의 두 기기 병합, 입력 중 응답 처리, 팀 이동, 순서 변경, 삭제 전파, 연결 코드, 기존 프로젝트 이관을 자동 검증한다. PC는 실제 Electron 렌더러에서 온보딩·건너뛰기·도구 팝업·월 뷰·날짜 편집·메뉴 테마를 검증한다. iPhone 실기기의 키보드/제스처와 로컬 네트워크 권한은 설치 후 실기기에서 최종 확인해야 한다.

서버 테스트 44개와 PC UI 검증이 통과했다. Android 에뮬레이터에서는 서명된 APK를 설치하고 연결 코드로 별도 테스트 서버에 연결한 뒤, 줄바꿈 입력·소프트 키보드 Backspace·양방향 스와이프·팀 선택 및 드래그·순서 변경·날짜 전용 팝업·테마 변경을 확인했다. Android 키보드가 입력 창을 가리는 문제도 보정했다. iOS는 1.1.0 / 빌드 4, Android는 1.1.0 / 버전 코드 3이다.
