# 1.1.4 — 할 일 출처 로고

메모장형 할 일 목록, 월 보기, 버킷에서 제목 옆에 Notion·Google Calendar·Apple Calendar 출처 아이콘을 표시합니다. 여러 소스를 합친 업무에는 출처별 로고를 나란히 표시하며, 같은 도구의 로고는 한 번만 표시합니다. 외부 연결이 없는 로컬 업무에는 아이콘을 붙이지 않습니다.

사용자가 제공한 PNG를 사용하며, 도구 연결 버튼에도 같은 로고를 적용했습니다. 로고는 편집 영역 밖에 있어 텍스트 편집·백스페이스·스와이프 조작을 유지합니다. PC에서는 마우스를 올리면 출처 이름을 볼 수 있습니다.

## 파일 위치와 명명

- PC: `desktop/src/assets/providers/`
- 모바일: `mobile/assets/providers/`
- 공통 파일명: `apple-calendar.png`, `google-calendar.png`, `notion.png`

파일 이름은 소문자 kebab-case로 통일했습니다. 루트에 있던 로고는 이동했으며 각 앱 빌드가 독립적으로 이미지를 포함하도록 두 앱에 동일한 파일을 둡니다. 이미지 원본 내용은 바꾸지 않았습니다.

## 설치

PC·Android·iPhone 앱 1.1.4로 업데이트하면 표시됩니다. 기존 서버와 연결 정보는 그대로 사용합니다. 이번 변경은 앱의 표시 기능이므로 서버 재시작은 필요하지 않습니다.

## 검증

PC UI 검사와 Android 에뮬레이터에서 단일 출처·여러 출처·로컬 업무의 표시를 확인했습니다. 메모장과 월 보기 화면을 검토했고, 두 앱에 포함된 로고 파일이 동일한지도 확인했습니다. iPhone 실기기 시각 확인은 업데이트 후 필요합니다.
