# 체커 1.1.1 — 메모장 UI 복원

1.1.0에서 과도하게 바꾼 메인 화면을 기존 메모장 구조로 복원했다.

- PC: 원래 크기의 상단바, 글자 크기, 날짜별 연속 메모장과 입력 줄을 유지한다. 떠 있는 큰 헤더와 메모장 스타일 덮어쓰기를 제거했다.
- 모바일: 월 달력 아래 하루 카드 대신, 기존 월 보기와 날짜별 연속 목록을 복원했다. 월 보기에서 날짜를 누르면 해당 날짜의 메모장으로 이동한다. 팀은 메모장 안의 작은 제목과 들여쓰기로 구분한다.
- 작은 헤더와 탭바, 기존의 은은한 기본 배경과 목록 간격을 복원했다. 블러와 지원 iPhone의 네이티브 글래스는 표면 효과로 유지한다.
- 제목을 바로 편집하고 줄바꿈으로 새 할 일을 작성한다. 빈 입력 줄의 Backspace는 이전 할 일로 이동하고, 기존 빈 줄은 삭제한다.
- 날짜 전용 팝업, 왼쪽 삭제·오른쪽 버킷 스와이프, 점 손잡이 길게 누르기·팀 이동·드래그 정렬은 유지한다.
- 첫 실행 도구 연결 화면, 도구별 연결 팝업, 팀 탭, 메뉴 테마, 개인 서버 동기화도 유지한다. 프로젝트·콘텐츠 캘린더·OpenAI 키·중복 개인 메모리 화면은 다시 표시하지 않는다.

## 설치

Windows는 `todo-checker-demo-Setup-1.1.1.exe`, Android는 `todo-checker-demo-1.1.1-android.apk`로 기존 앱을 업데이트한다. 기존 데이터를 지우거나 앱을 먼저 삭제할 필요가 없다.

iPhone은 Safari에서 [1.1.1 설치 페이지](https://expo.dev/accounts/teamblco/projects/todo-checker/builds/b57eeefc-aadc-48c4-87d9-1f0d6e8f86cb)를 열어 설치한다. 등록된 iPhone용 Ad Hoc 빌드이며 iOS 빌드 번호는 6, Android 버전 코드는 4이다.

서버와 계정 연결 설정은 이번 복원에서 변경하지 않았다. 이미 연결된 PC·폰은 그대로 사용한다. 처음 연결하는 경우 PC 메뉴의 ‘휴대폰 연결’에서 발급한 코드를 폰의 ‘PC 연결 · 동기화’에 입력한다. PC와 같은 Wi-Fi를 사용하고 Windows 방화벽과 iPhone 로컬 네트워크 접근을 허용해야 한다.

서버 실행 파일은 이 컴퓨터의 `%LOCALAPPDATA%\todo-checker\server-location.json`에 저장한 서버 폴더를 계속 사용한다. 이미 8787 서버가 실행 중이면 중복 실행하지 않고 안내만 표시한다. 새 앱 빌드를 설치해도 서버의 `.env`와 데이터 폴더를 새 빌드 폴더로 옮기지 않는다. 현재 고정된 폴더는 `artifacts/demo-2026-09-14/todo-checker-demo-server-windows-x64/todo-checker-demo-server`다. 재부팅 후에도 새 실행 파일에서 이 폴더의 서버를 시작한다. 이 서버 폴더는 삭제하지 않는다.

## 확인 범위

PC의 실제 Electron 렌더러에서 기존 메모장 연속 목록과 작은 헤더, 월 보기, 날짜 창, 도구 연결, 테마 검사가 통과했다. Android 설치본에서 월→날짜 이동, 줄바꿈 입력, 소프트 키보드 Backspace와 빈 줄 삭제, 키보드 위 입력 줄 유지, 길게 누르기·팀 드래그, 양방향 스와이프를 확인했다. iPhone 실기기의 최종 키보드·제스처 확인은 설치 후 필요하다.
