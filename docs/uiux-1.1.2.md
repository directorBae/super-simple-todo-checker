# 모바일 1.1.2 — PC 앱 없이 시작

메모장 UI는 1.1.1 그대로다. 모바일과 PC 앱은 같은 개인 서버에 각각 연결하는 클라이언트다. 모바일을 사용하기 위해 PC 앱을 설치하거나 실행할 필요가 없다.

## 모바일에서 시작하기

1. 모바일 1.1.2를 설치한다. [등록된 iPhone 설치 페이지](https://expo.dev/accounts/teamblco/projects/todo-checker/builds/0496a0a8-e53c-45f7-aa5b-705331d85e53)를 Safari에서 연다. iOS 빌드 번호는 7, Android 버전 코드는 5이다. PC 앱은 기존 1.1.1을 그대로 사용한다.
2. 처음 도구를 연결하거나 메뉴 → **서버 연결 · 동기화**를 열면 **내 서버에 로그인**이 나온다.
3. 서버 주소와 개인 서버 비밀번호를 입력한다. 현재 같은 Wi-Fi의 서버 주소는 `http://192.168.150.151:8787`이다. 서버 컴퓨터의 IP가 바뀌면 주소도 바꾼다.
4. 현재 서버 비밀번호는 `artifacts/demo-2026-09-14/todo-checker-demo-server-windows-x64/todo-checker-demo-server/data/login-password.txt`에 있다. 이 파일은 서버 설치 시 자동 생성하며 Git·ZIP·앱 설치본에 포함하지 않는다. 로그인 후 앱은 연결 정보를 저장하므로 매번 입력하지 않는다.
5. 모바일에서 Notion 토큰 또는 iCloud 계정을 연결하고, 데이터베이스/캘린더와 팀을 선택한다. PC 앱을 거칠 필요가 없다.

6자리 코드는 이미 연결된 PC 앱이 있을 때 선택할 수 있는 보조 연결 방법이다. 모바일의 첫 로그인에는 필요 없다. 아무 도구도 연결하지 않고 온보딩을 건너뛰어 메모장을 사용하는 것도 가능하다.

## 서버와 PC 앱 구분

PC 앱은 꺼도 된다. 지금은 서버 프로그램을 이 컴퓨터에서 실행하므로 컴퓨터와 서버 프로그램은 켜져 있어야 외부 도구·AI·동기화가 동작한다. 같은 Wi-Fi, Windows 방화벽의 8787 접속 허용, iPhone 로컬 네트워크 권한이 필요하다. 서버에 연결할 수 없는 동안 작성한 할 일은 휴대폰에 저장한다.

서버 폴더와 기존 `.env`·데이터·동기화 토큰은 유지했다. 로그인 기능 적용 전 백업을 `artifacts/server-backup-before-mobile-login-*`에 저장했다. 새 서버를 추가로 실행하지 말고 기존 `start-server.cmd`를 사용한다.

`start-server.cmd`를 다시 실행했을 때 서버가 이미 켜져 있으면, 창에 `ONLINE` 상태와 PC·휴대폰 주소를 표시하고 3초마다 상태를 확인한다. 이 상태 창의 `Ctrl+C`는 모니터만 종료하며 기존 백그라운드 서버는 계속 실행된다. 서버가 꺼져 있으면 저장된 서버 폴더에서 서버를 시작한다.

원하는 개인 비밀번호를 지정하려면 서버 `.env`의 `PERSONAL_PASSWORD`에 12~256자 비밀번호를 넣고 같은 서버를 재시작한다. 이 경우 자동 생성 파일의 값 대신 지정한 비밀번호로 신규 로그인한다. 이미 연결된 기기의 동기화 토큰은 바꾸지 않는다. 아직 다중 사용자 계정 기능은 아니다.

## Google 모바일 로그인에 남은 외부 설정

현재 Google 웹 OAuth 클라이언트의 콜백은 `http://localhost:8787/oauth/google/callback`이다. 휴대폰 브라우저에서 localhost는 휴대폰 자신이므로 이 설정으로는 모바일 Google 로그인이 완료되지 않는다.

서버는 이 컴퓨터에 유지하면서, 휴대폰에서 접근 가능한 HTTPS 주소를 프록시 또는 터널로 마련해야 한다. 예를 들어 그 주소가 `https://YOUR-SERVER.example`이면 다음 두 값을 맞춘다.

- 실제 서버 `.env`: `PUBLIC_URL=https://YOUR-SERVER.example`
- Google Cloud → 현재 OAuth 웹 클라이언트 → 승인된 리디렉션 URI: `https://YOUR-SERVER.example/oauth/google/callback`

같은 서버를 재시작하면 모바일의 Google 계정 로그인 버튼으로 휴대폰 브라우저에서 인증하고 앱으로 돌아올 수 있다. 로그인 완료 시 서버에 연결된 계정이 모바일에 표시된다. 임의의 HTTPS 주소를 적는 것만으로는 연결되지 않으며, 해당 주소가 실제 서버의 콜백 경로로 연결되어야 한다. 이 변경을 위해 PC 앱은 필요하지 않다.

Google은 웹 클라이언트 리디렉션 URI에 HTTPS를 요구하며 localhost에는 예외를 둔다. 등록값과 요청값도 일치해야 한다. [Google 공식 문서](https://developers.google.com/identity/protocols/oauth2/web-server#uri-validation)

## 검증

서버 테스트 46개가 통과했다. 모바일의 직접 로그인, PC 코드 없이 할 일 동기화·도구 목록 접근, 비밀번호 재시작 유지, 로그인 실패 제한과 브라우저 Origin 차단을 포함한다. Android/iOS 번들 내보내기도 통과했다. Android 새 설치 상태에서 서버 주소와 테스트 비밀번호로 로그인한 뒤 Notion 설정 진입·메모장 작성·앱 재시작 후 로그인 유지와 동기화 상태를 확인했다. 실제 서버 비밀번호를 이용한 자동 로그인 검증은 도구의 자동 승인 검토가 차단했으므로 격리된 테스트 자격 증명으로 검증했다. iPhone 실기기는 최종 확인이 필요하다.
