체커 개인정보처리방침

시행일: 2026년 10월 28일 · 운영: 배정원

체커(이하 “앱”)는 할 일을 기록하고, 사용자가 직접 연결한 노션·구글 캘린더의 내용을 할 일로 정리해 주는 앱입니다. 이 방침은 앱이 어떤 정보를 왜 다루는지 설명합니다.

1. 수집하는 정보

  • 계정 정보: 가입할 때 입력한 이메일 주소와 비밀번호(비밀번호는 암호화되어 저장되며 운영자도 볼 수 없습니다).
  • 앱에 적은 내용: 할 일, 팀, 프로젝트, 날짜·시간 등 사용자가 앱에 입력한 내용.
  • 연결한 도구의 정보: 사용자가 구글 캘린더나 노션을 연결하면, 연결 토큰과 사용자가 고른 캘린더 일정·노션 페이지의 내용(제목, 날짜, 완료 여부, 본문)을 읽습니다.

2. 정보를 쓰는 목적

  • 사용자의 할 일을 여러 기기(PC·휴대폰·웹)에서 같게 보여 주기 위해.
  • 연결한 캘린더·노션의 내용을 이번 주 할 일로 정리하고(일별 분류, 50자 이내 제목), 앱에서 바꾼 날짜·시간을 원래 캘린더 일정이나 노션 항목에 다시 반영하기 위해.
  • 그 밖의 목적(광고, 판매, 프로필 분석 등)에는 쓰지 않습니다.

3. 다른 곳으로 보내는 정보

  • Supabase: 계정과 할 일, 연결 정보는 Supabase(데이터베이스·인증 서비스)에 저장됩니다. 각 사용자는 자기 데이터만 읽고 쓸 수 있습니다.
  • OpenAI: 연결한 캘린더·노션 내용을 할 일로 정리할 때, 그 내용을 OpenAI API로 보내 처리합니다. 요청은 저장하지 않도록(store: false) 보내며, OpenAI는 API 데이터를 모델 학습에 쓰지 않습니다.
  • 법령에 따른 요청이 있는 경우를 빼고는 이 밖의 제3자에게 제공하지 않습니다.

4. 구글 사용자 데이터

체커가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 것은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 체커는 구글 캘린더 데이터를 사용자의 할 일 목록을 만들고 일정 시간을 맞추는 데에만 쓰며, 사람이 읽거나 광고에 쓰거나 다른 사람에게 넘기지 않습니다.

5. 보관과 삭제

  • 정보는 계정이 있는 동안 보관합니다.
  • 설정 → 도구 연결에서 “연결 끊기”를 누르면 그 도구의 토큰과 구독 정보가 바로 지워집니다. 구글 계정 설정(myaccount.google.com/permissions)에서도 언제든 접근을 끊을 수 있습니다.
  • 계정과 모든 데이터를 지우려면 아래 연락처로 요청해 주세요. 요청을 받으면 지체 없이 삭제합니다.

6. 보호 조치

모든 통신은 HTTPS로 암호화되며, 연결 토큰은 앱 화면에서 볼 수 없도록 서버 쪽에만 보관합니다.
